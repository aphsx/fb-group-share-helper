# FB Group Share Helper

ส่วนขยาย Chrome (Manifest V3) สำหรับ**การศึกษา/ใช้งานส่วนตัว** — ช่วยแชร์โพสต์ Facebook ที่เปิดอยู่ไปยังกลุ่มที่คุณเป็นสมาชิก **ทีละกลุ่ม** พร้อมหน่วงเวลสุ่ม หรือ **โพสต์ข้อความใหม่ + รูปภาพ** เข้ากลุ่มตามรายการ

**ไม่ใช่** สำเนาหรือ reverse-engineer ของส่วนขยายเชิงพาณิชย์ใดๆ (เช่น MGSA / Post Booster)  
เขียนใหม่ทั้งหมด · ไม่มี watermark · ไม่มี license server

เวอร์ชันปัจจุบัน: **1.2.10**

---

## คำเตือนสำคัญ (อ่านก่อน)

1. **Meta / Facebook Terms of Service** — การโพสต์อัตโนมัติอาจผิดนโยบายของ Meta และอาจทำให้บัญชีถูกจำกัดหรือระงับ ใช้บนความรับผิดชอบของคุณเอง และใช้เฉพาะกลุ่มที่คุณมีสิทธิ์โพสต์
2. **UI ของ Facebook เปลี่ยนบ่อย** — สคริปต์ใช้ selector แบบ best-effort (`aria-label`, ข้อความปุ่ม) อาจพังได้ทุกเมื่อ
3. **หน่วงเวลา** — ค่าเริ่มต้น 60–120 วินาที เพื่อลดความเสี่ยงพฤติกรรมเหมือนบอท อย่าตั้งต่ำเกินไป
4. ส่วนขยายนี้**ไม่เก็บรหัสผ่าน** และไม่ส่งข้อมูลไปเซิร์ฟเวอร์ภายนอก (ใช้แค่ `chrome.storage.local` ในเครื่องคุณ)
5. **รูปใน storage** — รูปที่เลือกจะถูกเก็บเป็น data URL ใน `chrome.storage.local` (จำกัดประมาณ 5 ใบ / เตือนถ้ารวมใหญ่เกิน ~4 MB) เพื่อให้แนบซ้ำได้ทุกกลุ่มโดยไม่ต้องเลือกไฟล์ใหม่

---

## วิธีโหลดแบบ Unpacked

1. เปิด Chrome แล้วไปที่ `chrome://extensions`
2. เปิด **Developer mode** (มุมขวาบน)
3. กด **Load unpacked** (หรือ **Reload** ถ้าเคยโหลดแล้ว)
4. เลือกโฟลเดอร์ `fb-group-share-helper` (โฟลเดอร์ที่มี `manifest.json`)
5. ควรเห็นไอคอนส่วนขยายบนแถบเครื่องมือ
6. กดไอคอนขณะเปิด Facebook แผงควบคุมจะติดด้านขวาของหน้าต่าง หน้า Facebook อยู่ซ้าย

## โหมดการทำงาน

### 1) แชร์โพสต์ (Share) — เหมือนเดิม

1. เปิด Facebook ในแท็บหนึ่ง แล้วเปิด**โพสต์ที่ต้องการแชร์** (permalink ยิ่งดี)
2. คลิกไอคอนส่วนขยาย → เลือกโหมด **แชร์โพสต์**
3. วางรายการกลุ่ม บรรทัดละ 1 รายการ (URL / ID / slug)
4. (ถ้าต้องการ) ใส่ข้อความกำกับในช่อง caption
5. ตั้งช่วงหน่วงเวลา → **บันทึกรายการ** → **เริ่ม**

- **Strategy A:** Share → Share to a group → เลือกกลุ่ม → Post  
- **Strategy B (สำรอง):** ไปหน้ากลุ่ม → เปิดช่องโพสต์ → วาง caption + ลิงก์โพสต์ → Post  

### 2) โพสต์ใหม่ (Auto Post) — ข้อความ + รูป (v1.2)

โพสต์**ข้อความและ/หรือรูปภาพ**เข้าแต่ละกลุ่มทีละกลุ่ม (ไม่ต้องเปิดโพสต์เดิม) — เลือกรูปครั้งเดียว แล้วคิวจะแนบซ้ำทุกกลุ่ม

**แนบรูป 3 ขั้นตอน**

1. เปิดโหมด **โพสต์ใหม่** → ใส่ข้อความ (ถ้ามี) → กดเลือกไฟล์รูป (`image/*` สูงสุด 5 ใบ) ดูตัวอย่าง thumbnail  
2. วางรายการกลุ่ม → กด **บันทึกรายการ** (รูปถูกเก็บใน storage)  
3. กด **เริ่ม** — ส่วนขยายไปหน้ากลุ่มทีละกลุ่ม → เปิด composer → พิมพ์ข้อความ → ใส่ไฟล์ลง `input[type=file]` → กด โพสต์/Post  

ต้องมี**ข้อความหรือรูปอย่างน้อยอย่างใดอย่างหนึ่ง**

กด **หยุด** ได้ทุกเมื่อ · กด **ล้างรูป** เพื่อลบรูปที่เลือก

**v1.2.1:** พิมพ์เข้าช่อง Write something แบบ Lexical/React ให้แน่นขึ้น และ**ไม่รายงานสำเร็จ**ถ้า composer ยังว่างหรือปุ่ม Post ยัง disabled

**v1.2.2:** ไม่กด **Share now** / ไดอะล็อก Share แล้วขึ้นสำเร็จอีกต่อไป — รับเฉพาะปุ่ม Post ใน Create post และปิด Share ถ้าเผลอเปิด

**v1.2.3:** กล่อง Create post ของ Facebook มี dialog ชื่อ Create post สองชั้น — เลือกชั้นที่มีช่อง Write something ไม่ใช่แถบหัวข้อที่ไม่มีช่องพิมพ์

**v1.2.4:** ช่องรายการกลุ่มไม่ถูกล้างหลังพิมพ์เสร็จ และติ๊กชื่อกลุ่มที่เปิดอยู่เพื่อเพิ่มหรือเอา URL ออกได้

**v1.2.5:** พิมพ์ข้อความโพสต์ครั้งเดียว ถ้าช่องมีข้อความนั้นแล้วจะไม่พิมพ์ซ้ำ

**v1.2.6:** กดโพสต์เมื่อปุ่มพร้อมและรอจนกล่องปิด รูปที่เลือกในแผงจะค้างไว้แล้วแนบเข้าโพสต์

**v1.2.7:** พิมพ์คำบรรยายด้วยคำสั่งเดียว เลิกวาง paste ซ้ำในเฟรมเดียวกันเพราะ Lexical ยังไม่อัปเดตข้อความทันที

**v1.2.8:** แนบรูปก่อนแล้วค่อยพิมพ์ เพราะรูปทำให้ช่องเขียนถูกสร้างใหม่และข้อความหาย ถ้ารูปขึ้นในกล่องแล้วถือว่าแนบสำเร็จ และปิดกล่องก่อนไปกลุ่มถัดไปเพื่อไม่ให้ขึ้น Leave site

**v1.2.9:** กดไอคอนแล้วแผงควบคุมติดด้านขวาของหน้า Facebook แทนป๊อปอัปเล็ก นับว่าโพสต์สำเร็จเมื่อ Facebook ขึ้นข้อความ «โพสต์สำเร็จ» เอง แล้วค่อยไปกลุ่มถัดไป

**v1.2.10:** ถ้าไม่มีข้อความ «โพสต์สำเร็จ» แต่กล่องปิดแล้ว หรือโพสต์ขึ้นบนฟีดคำว่า Just now / เมื่อสักครู่ ให้นับสำเร็จ ไม่ขึ้น error ทั้งที่โพสต์ไปแล้ว

**ไม่มี** Marketplace · ไม่มีการตั้งเวลาโพสต์ · ไม่ reverse-engineer เครื่องมือเชิงพาณิชย์

## ข้อจำกัดที่ทราบ

- ไม่รองรับ MFA/login — คุณต้องล็อกอิน Facebook เองอยู่แล้ว
- หลังนำทางไปหน้ากลุ่ม หน้าจะโหลดใหม่ แล้ว content script พยายามโพสต์ต่อ (อาจพลาดถ้า UI ช้า)
- กลุ่มที่ปิดการโพสต์ / ต้องอนุมัติแอดมิน จะ “ส่งคำสั่ง” ได้แต่โพสต์อาจไม่ขึ้น
- Chrome MV3 service worker อาจ sleep — ใช้ `chrome.alarms` เป็นตัวตั้งเวลาหน่วง
- ไม่มีระบบคลาวด์ / sync ข้ามเครื่อง
- Auto Post รูป: สูงสุด **5 ใบ** · เตือนถ้า payload รวมประมาณ **> 4 MB** (ขีดจำกัด `chrome.storage.local`) · DOM แนบไฟล์เป็น best-effort อาจพังเมื่อ Facebook เปลี่ยน UI
- ไม่มี Marketplace / scheduling

สร้างขึ้นเพื่อการเรียนรู้ automation บน DOM ที่เปลี่ยนบ่อย — ใช้ด้วยความระมัดระวัง และเคารพ Meta ToS
